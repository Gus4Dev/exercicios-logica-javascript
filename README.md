Repositório criado para armazenar meus exercícios e estudos de **Lógica de Programação utilizando JavaScript**, desenvolvidos durante meus estudos e atividades do curso ( **INSTITUTO PROA** )

# 💻 Exercícios de Lógica de Programação - JavaScript

Repositório contendo resoluções de exercícios de lógica de programação desenvolvidos em **JavaScript**, com base nas apostilas Faccat e Manzano. O objetivo é praticar os fundamentos da programação, incluindo variáveis, operadores, estruturas condicionais e laços de repetição.

---

## 📁 Estrutura do Repositório

O projeto está organizado nas seguintes pastas:

```text
exercicios-logica-javascript/
├── Exercícios FacCat - JavaScript/    # Exercícios da apostila Faccat
└── Exercícios Manzano - JavaScript/   # Exercícios da apostila Manzano
```

> **Nota:** Os arquivos estão identificados pela numeração correspondente a cada exercício nas apostilas de referência.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** JavaScript
- **Estrutura:** HTML para execução dos exercícios no navegador, conforme a implementação de cada arquivo
- **Editor de código:** [Visual Studio Code](https://code.visualstudio.com/)
- **Controle de versão:** [Git](https://git-scm.com/) e [GitHub](https://github.com/)

---

## 🚀 Como Executar os Arquivos

1. Instale o [Visual Studio Code](https://code.visualstudio.com/), caso ainda não tenha.
2. Baixe o arquivo `.ZIP` do repositório pelo botão verde **Code > Download ZIP** e extraia os arquivos no computador.
3. Abra a pasta do projeto no Visual Studio Code.
4. Acesse a pasta correspondente à apostila e escolha o exercício desejado.
5. Execute o código conforme sua estrutura: abra o arquivo HTML no navegador ou utilize o ambiente de execução configurado para o JavaScript.
